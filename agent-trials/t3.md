## Task T3 — interpreter in C++ or C
Implement a small expression-language interpreter (integers, floats, strings, variables, if/while, functions,
recursion, closures if you can) with a REPL-less file runner: `run prog.txt` prints program output.
Write a test suite of >= 15 example programs with expected output and a test runner, run entirely through the
service. Use C++ (C++17) unless C++ proves impractical in the service — if so, record why and switch to C.
