## 2. Friction log
- `go test -update ./md` (flag before package): go passed `-update` to the root package's test binary too, which doesn't define it -> `flag provided but not defined: -update` plus ~60 lines of usage output. This is standard Go behavior, not a service bug; `go test ./md -update` works. ~1 min lost.
- My own mistake: shell `cmd` does not support `VAR=1` assignments or `head`; error was clear (`wasmdev: head: command not found (neither a registered tool/command, a builtin, nor a file in the workspace)`). Using `| cat` works. A tiny set of coreutils (head, wc, grep) would help.
- Output of long `go test -v` is easier to read via a file + `cat`; piping is buffered but fine.
- Uploading: tar upload works well; there is no way to download a tree (had to GET each file). A tar download endpoint would help.
- I used a local `gofmt -l` once (formatting only, not building/testing) and it flagged md_test.go as unformatted; I did not run `gofmt` through the service. Disclosing in case that counts as a rule bend. `gofmt` was not tested as a service command.
- No other service problems; no flakiness seen.
