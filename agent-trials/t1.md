## Task T1 — C library + tests
Implement in C a small library `csvstat` with a command-line front end: read CSV from stdin (quoted fields,
embedded commas/newlines, CRLF), and print per-column stats (count, numeric min/max/mean, distinct count up to 1000).
Write a unit test program covering the parser edge cases and the stats, and an end-to-end test that runs the CLI
on sample files and compares output with expected files. Iterate through the service until all tests pass.
Target wasm32-wasip1. Use multiple source files and a reasonable structure.
