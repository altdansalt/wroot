## Task T4 — Go network service
Write a Go (stdlib only) URL-shortener HTTP service: `POST /api/links` {url} → {code, short_url}; `GET /<code>` → 302 redirect;
`GET /api/links/<code>` → stats JSON (hits, created); `GET /healthz`. Validate URLs, generate collision-free codes,
be safe under concurrent requests. Write table-driven unit tests and an httptest-based handler test; run `go vet` and
`go test` through the service until green. Build it, start it as a long-running service through the service API, and test
it over the network from your machine with a bash+curl script. Leave it running and put its URL in the report.
