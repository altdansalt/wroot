## Task T6 — Go CLI with golden tests
Write a Go (stdlib only) Markdown-subset to HTML converter CLI (`md2html < in.md > out.html`): headings, paragraphs,
emphasis/strong, inline code, fenced code blocks (HTML-escaped), ordered/unordered nested lists, links, blockquotes,
horizontal rules. Use packages across the stdlib where natural (regexp, strings, bufio, html, text/template or
html/template for a page wrapper with a `-page` flag, flag, encoding/json for a `-toc-json` flag that prints the heading
outline). Golden-file tests (testdata/*.md + *.html) with a `-update` flag, plus fuzz-style property tests
(`testing` only). Run everything through the service until green; also run the built binary through the service on the
golden inputs to show the CLI works end to end.
