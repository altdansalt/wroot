## Task T2 — network service
Write in C a small HTTP/1.1 key-value store service: `PUT /kv/<key>` stores the body, `GET /kv/<key>` returns it
(404 if missing), `DELETE /kv/<key>`, `GET /kv` lists keys as JSON, plus `GET /healthz`. Handle multiple
sequential connections, Content-Length bodies up to 1 MB, and keep-alive if you can.
Build it through the service, start it as a long-running service, and test it **over the network from your own
machine** (through the URL the service gives you). Write a test script (bash+curl) that exercises it and include its
output in the report. Also write C unit tests for your request parser and run them through the service.
Leave the service running at the end and put its URL in the report.
